# Guides Index

All how-to guides live here. Guides are **normative documents**: they state the current method, carry no history, and are updated in place (see `docs/guides/doc-organization.md`).

Before doing any of the following, read the matching guide first — `AGENTS.md` Task Routing points here.

| You are about to... | Read |
| --- | --- |
| place/names any document, or wonder where a file belongs | `doc-organization.md` |
| write or update a roadmap | `roadmap-authoring.md` |
| execute requirement → roadmap → goal-directed delivery | `roadmap-goal-execution.md` |
| write, execute, review, or close a plan | `plan-authoring-and-execution.md` |
| run a document audit, draft review, or closure audit | `audit-execution.md` |
| hand off a non-trivial change (pre-flight self-check) | `change-handoff-checklist.md` |
| after a change lands, sync repo memory | `doc-maintenance-checklist.md` |
| synthesize requirements from raw input | `requirements-synthesis.md` (+ `input-processing.md`) |
| record a requirement clarification discussion | `discussion-writing.md` |
| write a bug-fix note | `bug-fix-note.md` |
| write the daily dev log | `log-writing.md` |
| record manual/exploratory testing | `testing-note.md` |
| follow the default development workflow end to end | `application-development-workflow.md` |
| look up coding conventions | `coding-conventions.md` |

## Adding A Guide

New guides follow the same rules as any normative doc: stable name, present tense, no changelog. Add the row here and (if task-relevant) a row in `AGENTS.md` Task Routing in the same change.
