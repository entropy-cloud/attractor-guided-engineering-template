# Java Shelf

Skills for Java backend business systems. Starter set — extend from the project's real recurring audit needs, and prune what you do not use.

| Skill | One-liner |
| --- | --- |
| `api-and-transaction-design-review-prompt.md` | challenge an API/transaction design on contract, consistency, and compatibility before implementation |
| `backend-regression-audit-prompt.md` | audit a backend change for behavioral and data regressions before closure |

## Project Customization Layer

Before first use, add to each prompt's customization section: framework/stack versions, transaction and isolation conventions, error-taxonomy doc, API compatibility policy, data-migration rules, and the project's known backend failure modes.
