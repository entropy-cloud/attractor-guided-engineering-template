# Frontend Shelf

Skills for frontend, low-code, and component-heavy projects. Starter set — extend from your project's real recurring review needs, and prune what you do not use.

| Skill | One-liner |
| --- | --- |
| `component-design-review-prompt.md` | challenge a component's contract, states, and boundaries before it lands |
| `exploratory-e2e-testing-prompt.md` | run an adversarial user-journey pass and record durable evidence |

## Project Customization Layer

Before first use, add to each prompt's customization section: the design-system/component-library paths, rendering framework and version constraints, state-management rules, accessibility bar, browser matrix, and the project's known visual/interaction failure modes.
