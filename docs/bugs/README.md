# Bugs

## Purpose

`docs/bugs/` owns non-obvious bug histories and regression notes — a timeliness library referenced by issue identity.

Writing rules and format: `docs/guides/bug-fix-note.md`.

- fixed non-obvious regressions get a numbered note (`01-short-name.md`) when the library will grow, or dated names otherwise
- every non-trivial bug fix adds or updates automated test coverage (see `docs/guides/bug-fix-note.md`)
- unfixed findings do not live here — they go to the roadmap as work items or a defect ledger
