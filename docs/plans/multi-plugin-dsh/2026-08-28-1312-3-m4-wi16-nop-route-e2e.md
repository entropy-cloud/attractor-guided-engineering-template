- `plugin/nop-route/scripts/e2e-noproute.mjs` + `test/fixtures/e2e-noproute.cordis.yml` 落地：in-process 真 cordis runtime boot（dsh-app-boot `boot()`）+ 真四路由调用（经 `ctx.get('noproute')` 直调 `noproute.route` / `classify` / `pick-model` / `health`）。
